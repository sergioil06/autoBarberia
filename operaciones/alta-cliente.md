# Alta de un cliente nuevo

1. Crear `clientes/<slug>/` copiando `clientes/llano-gijon/` y rellenar `negocio.json` (no dejar datos de Llano).
2. Crear el proyecto en Supabase (o una fila nueva en la plataforma compartida) y aplicar las migraciones en orden.
3. Cargar servicios, barberos y horarios desde el panel o con `seed` propio.
4. Publicar la web y comprobar reserva de punta a punta (reservar, cambiar, cancelar).
5. Activar solo las automatizaciones contratadas en `negocio.json`.
6. Registrar el cliente en `operaciones/clientes.md`.
7. Firmar el contrato y la aceptación de tratamiento de datos (encargado del tratamiento).
